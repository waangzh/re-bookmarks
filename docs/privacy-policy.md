# ReMarks 隐私说明

生效日期：2026-09-20

ReMarks 是在浏览器本地运行的书签整理扩展。它不会提供账号体系、服务器端数据库或广告追踪；你选择的 AI 服务商是唯一可能接收分类请求内容的第三方。

## 本地保存的数据

扩展通过浏览器的本地扩展存储保存设置、AI Provider 配置、API Key、分类偏好、推荐、预览任务、执行报告和最近的书签备份。API Key 不会写入报告、备份或导出文件。

书签树、移动、删除、导入、恢复和撤销都通过浏览器本地书签 API 执行。除非你开启并使用 AI 分类，ReMarks 不会把书签内容发送到设备外。

## 发送给 AI Provider 的数据

你需要先在设置中测试连接，再主动开启“允许向此服务发送分类数据”。开启后，ReMarks 才会向你选择的 Provider 发送生成分类建议所需的内容：

- 书签标题、域名和现有文件夹路径；
- 默认移除 query 与 hash 后的 URL；只有开启“发送完整 URL”时才发送完整 URL；
- 可访问页面的标题、描述、Open Graph 标题、描述和站点名称等元数据；
- 已保存的分类偏好中与本次分类相关的目录修正、域名偏好和拒绝规则。

分类建议不会自动移动书签。移动、创建目录、删除和恢复仍须在扩展界面中由你确认。

API Key 仅用于向所选 Provider 的 API 请求添加认证头，不会发送给 ReMarks 的任何服务。AI Provider 对收到内容的保存、使用和删除由其自身隐私政策约束，请仅使用你信任的 Provider。

## 网站访问权限

Firefox 版本会在你主动测试 AI、开始 AI 整理、重新尝试推荐或启动链接检测时请求网站访问权限。此权限用于连接自定义 AI endpoint、读取书签页面元数据和检测链接状态。拒绝或撤销后，AI 任务、元数据和链接检测会显示授权提示或降级；本地书签浏览、备份和手动管理仍可使用。

## 浏览历史

浏览历史是可选权限。只有你主动开启“常访问书签”并授予 `history` 权限后，ReMarks 才会在本地统计最近 90 天内已收藏网址的访问次数。浏览历史不会发送给 AI Provider，也不会写入报告、备份或导出内容。拒绝或撤销该权限会关闭此功能，不影响其他功能。

## 数据控制

你可以在设置中关闭 AI 数据发送和常访问书签，在扩展界面中删除推荐、备份、报告或分类偏好。卸载扩展或通过浏览器清除扩展数据会删除浏览器本地存储的数据；请先导出或保留需要的备份。
